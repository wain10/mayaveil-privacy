Informativa sulla privacy di MayaVeil

Schopenhauer’s Lab non gestisce alcun server per MayaVeil. L’app non ci invia cronologia, ricerche, contenuti delle pagine, file, password o impostazioni. Non tracciamo come usi l’app. MayaVeil elabora le pagine e i file sul tuo dispositivo. Una copia che scegli di salvare o condividere può rimanere dopo la sessione.

Chi sviluppa MayaVeil?

MayaVeil è un’app Android sviluppata da Schopenhauer’s Lab. Per domande o richieste sulla privacy, scrivi a schopenhauerslab [at] proton [dot] me.

Cosa succede mentre navigo?

Puoi usare MayaVeil senza creare un account. L’app gestisce gli indirizzi web, le ricerche, i contenuti delle pagine, i cookie e i dati che inserisci nei siti per caricare le pagine e mantenere attivi gli accessi durante la sessione. MayaVeil non integra servizi pubblicitari o di analisi dell’utilizzo.

Quando apri una pagina, il sito e i servizi che carica possono ricevere il tuo indirizzo IP e le informazioni che invii. Le ricerche vengono inviate al motore che scegli. Il gestore della rete e il fornitore DNS possono vedere informazioni sulla connessione. MayaVeil Basic si collega direttamente, quindi i siti possono vedere il tuo indirizzo IP.

I siti possono usare la fotocamera o la posizione?

MayaVeil Basic rifiuta le richieste dei siti di accedere alla posizione, alla fotocamera e al microfono o di inviare notifiche. Può riprodurre audio e video durante la sessione.

Chi verifica la sicurezza dei siti?

MayaVeil usa il motore GeckoView di Mozilla con Google Safe Browsing. Il motore può contattare Google e Mozilla per aggiornare gli elenchi delle minacce o le impostazioni di sicurezza e verificare possibili minacce. Queste richieste possono rivelare il tuo indirizzo IP e informazioni necessarie al controllo di un sito. Per verificare un certificato, il motore può anche contattare l’autorità che lo ha emesso. Ogni servizio applica i propri tempi di conservazione. MayaVeil disattiva i controlli in tempo reale di Safe Browsing e configura il motore per disattivare l’invio della telemetria e il sistema di segnalazione degli arresti anomali.

Cosa succede ai file che apro, salvo o condivido?

I file che apri dal dispositivo rimangono al loro posto. Android concede a MayaVeil l’accesso in lettura al file selezionato. L’app mostra in memoria i PDF, le immagini, i testi, le tabelle CSV, i file JSON e i contenuti audio e video supportati. Sulle versioni compatibili di Android, la password che inserisci per un PDF protetto serve a mostrarne le pagine sul dispositivo. Quando chiudi un file aperto separatamente, MayaVeil cancella la copia di lavoro del lettore e torna alla schermata iniziale.

Se condividi un link, l’app che scegli riceve l’indirizzo di origine. Se condividi un file, quell’app può leggerlo e conservarne una copia. Se salvi un file, una copia rimane nella posizione scelta finché non la elimini. Per trasferire un file MayaVeil ne conserva una copia separata in RAM. L’accesso scade dopo dieci minuti, oppure prima se il salvataggio termina o viene annullato.

Cosa succede quando archivio una pagina?

Se scegli Archivia questa pagina, MayaVeil crea una copia di sola lettura della versione stampabile della pagina. Può contenere dati personali visibili nella pagina, anche dopo l’accesso a un sito. MayaVeil comprime la copia sul dispositivo nel formato di archivio che scegli. Scegli tu dove salvarlo o a quale app inviarlo.

Con Archivia un file puoi anche comprimere un documento originale di qualsiasi formato, fino a 32 MiB. Il nome e il contenuto del file sono inclusi nell’archivio. Una volta aperto puoi salvarne l’originale o visualizzare un formato supportato. La creazione dell’archivio non esegue il contenuto e non modifica il file di origine.

ZIP standard crea sul dispositivo un file .zip non cifrato. Chiunque abbia l’archivio può vedere i nomi dei file ed estrarne il contenuto con un normale gestore ZIP, senza MayaVeil né password.

Con Password, il file viene cifrato sul dispositivo. Chi ottiene sia il file sia la password corretta può leggerlo con un lettore compatibile. Non riceviamo né il file né la password e non disponiamo di una chiave di recupero. Con Copia pubblica, chiunque riceva il file può aprirlo e inoltrarlo senza password. MayaVeil apre entrambi i tipi di archivio in memoria. Le copie già salvate o condivise rimangono dopo la fine della sessione.

Un link in chiaro mostra l’indirizzo all’app o alla persona con cui lo condividi. Un link protetto contiene solo l’indirizzo cifrato, nella parte del link HTTPS dopo il simbolo # oppure in un file .maya. MayaVeil cifra e decifra l’indirizzo sul dispositivo. Aprendo il link HTTPS in un altro browser, il gestore del nostro sito statico può ricevere i normali dati di connessione. Il browser non invia la parte dopo il simbolo # in quella richiesta. Inserisci la password in MayaVeil. Dopo lo sblocco, l’app si collega alla destinazione come nella normale navigazione.

Cosa viene cancellato a fine sessione?

La sessione termina se passi a un’altra app, blocchi il telefono, la chiudi dal menu o scade il tempo di inattività che hai scelto. Anche aprire la schermata Android di condivisione o salvataggio termina la navigazione. La versione distribuita chiede ad Android di bloccare gli screenshot e nascondere la pagina nelle app recenti.

Quando esci dall’app o termini la sessione, MayaVeil la chiude e cerca di sovrascrivere le aree di memoria scrivibili che gestisce per i file prima di liberarle. Il motore del browser può anche scrivere file temporanei sul dispositivo. MayaVeil rimuove i file di sessione durante la pulizia e riprova all’avvio successivo se l’operazione è stata interrotta.

Android, la tastiera, i siti e le app con cui condividi contenuti possono conservarne copie proprie. Chiudere MayaVeil non elimina queste copie né i file che hai salvato. Per cancellare dati che hai inviato a un sito, rivolgiti al gestore di quel sito.

Quali impostazioni rimangono sul dispositivo?

Il motore di ricerca scelto, l’aspetto, la posizione della barra di navigazione e il tempo di inattività dopo il quale la sessione si chiude sono cifrati sul dispositivo ed esclusi dal backup di Android. Per eliminare le preferenze e la chiave di cifratura, apri le impostazioni di MayaVeil e scegli Dimentica impostazioni. Puoi anche cancellare i dati dell’app dalle impostazioni di Android.
